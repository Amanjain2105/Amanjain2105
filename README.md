### Engineering Principles

* **Measure before optimizing.** Use benchmarks and profiling rather than intuition.
* **Make failure modes explicit.** Understand timeouts, backpressure, stale data, and inconsistent state.
* **Test invariants, not just examples.** Verify the properties that must always hold.
* **Document trade-offs.** Explain architectural decisions, limitations, and what the measurements actually demonstrate.
